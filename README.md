# 文字コード変換シミュレータ

情報Ⅰ「情報のデジタル表現」（実教出版『最新情報Ⅰ』第3章 1-2 文字のデジタル化）の授業用シミュレータ．

## できること

- **変換する**：入力した文字列を，1文字ずつ ASCII・JISコード・Shift_JIS・EUC-JP・UTF-8・UTF-16 のバイト列に変換して並べる．16進数と2進数（ASCIIは7ビット）を切り替えられる
- **文字化けの実験**：0と1にする方式（エンコード）と読む方式（デコード）を自由に選ぶ．どこで区切って読んだかを図で示す．化けた文字列を入れて，読み直して元に戻すこともできる．表せない文字が「?」になったり，読めない並びが「�」になったりして情報が失われたときは，朱色で知らせる
- **文字コード図鑑**
  - 6つの文字コード：生まれた時期，1文字の大きさ，今も出会う場面
  - ASCIIコードの表：上位3ビット×下位4ビットの表．マスを押すと2進数・16進数・10進数を表示
  - JISの対応表：94の区を切り替えて全部見られる．マスの下の番号を JIS・Shift_JIS・EUC-JP・Unicode で切り替えられる
  - Unicodeの表：基本ラテン文字・ひらがな・カタカナ・漢字（82ページ）・全角英数字・絵文字のブロックを，256字ずつ表示する．マスの下の番号を Unicodeの番号・UTF-8・UTF-16 で切り替えられる．ブロックごとに公式の表（Unicode Code Charts のPDF）へのリンクがある

## 授業で使うときのURL

| URL の末尾 | 開く画面 |
|---|---|
| `#convert` | 変換する |
| `#mojibake` | 文字化けの実験 |
| `#guide` | 文字コード図鑑（一覧） |
| `#ascii` | ASCIIコードの表 |
| `#jis-4` | JISの対応表の4区（ひらがな）．数字を変えると別の区 |
| `#unicode-hiragana` | Unicodeの表のひらがな．`latin`・`katakana`・`kanji`・`fullwidth`・`emoji`・`smiley` も使える |

`?q=文字列` で最初の文字列を指定できる（例：`?q=あ#convert`）．文字化けの実験では `?enc=` と `?dec=` で方式も指定できる（`ascii`・`jis`・`sjis`・`euc`・`utf8`・`utf16`．例：`?q=縺薙ｓ縺ｫ縺｡縺ｯ&enc=sjis&dec=utf8#mojibake`）．

## しくみ

- `index.html` 1ファイルで動く．外部のライブラリやフォントは読み込まない
- ブラウザの `TextDecoder` はShift_JISやEUC-JPを読めるが書けないため，読み込み時にすべてのバイト列を読ませて「文字 → バイト列」の表を逆向きに作っている
- JISコードの欄は，教科書と同じくJIS X 0208の番号（例：あ → 24 22）を表示する．文字化けの実験では，実際のファイルで使われる切り替えの記号付きの形式（ISO-2022-JP）で符号化する
- 入力した文字はブラウザの中だけで処理し，どこにも送信しない
